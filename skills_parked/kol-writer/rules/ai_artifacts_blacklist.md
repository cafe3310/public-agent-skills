# AI 腔调黑名单与改写替换建议

在精细化润色阶段，Agent 必须扫描初稿并替换以下高频出现的“机器腔调”词汇，以确保文案自然、像人类手写。

---

## 1. 禁用词/黑名单列表

| 禁用词 (AI 腔调) | 替换建议 (人类口语/低调转折) | 改写逻辑 |
| :--- | :--- | :--- |
| **值得一提的是** / **不得不说** | 顺带提一句 / 甚至 / 实际上 | 消除突兀的强调，使其融入自然语流。 |
| **总而言之** / **综上所述** | 简单来说 / 一句话 / 说白了 | 避免学术化、大纲式的生硬总结。 |
| **不可否认** / **毋庸置疑** | 确实 / 的确 | 去除说教和绝对化语气。 |
| **扮演着重要的角色** | 很关键 / 很有用 / 离不开它 | 消除机械的翻译腔（play an important role）。 |
| **如前所述** / **正如我们所知** | （直接删除，或用“之前提到...”） | 避免重复叙述的死板引用。 |
| **双刃剑** | 有利有弊 / 也有点代价 / 坑在... | 消除流于表面的万能公式化比喻。 |
| **不仅...而且...**（过度并列） | 拆分为两个短句，直接陈述 | 减少刻板的语法套路。 |

---

## 2. 句式去 AI 化原则

1. **拒绝“排排坐”并列段落**：
   - *AI 习惯*：“首先，...；其次，...；最后，...”。
   - *改写后*：使用讲故事的因果链条，或者直接用“第一、第二”等口语化词汇引出。
2. **拒绝“绝对正反对比”**：
   - *AI 习惯*：“虽然它有A的优点，但是它也存在B的缺点，我们需要在两者之间平衡。”
   - *改写后*：用更接地气的实测语调：“这个功能看似好用，其实有个隐形大坑：...”
3. **增加“主观感叹与语气词”**：
   - 适当加入“其实”、“说实话”、“难顶”、“真香”等自媒体博主常用语气词，打破机械的句法结构。
