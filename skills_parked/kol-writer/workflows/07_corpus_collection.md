# 子流程 07: 语料收集与加工 (Corpus Collection Workflow)

## 1. 目标
语料收集整理流程。规范自媒体写作样例的收集、图像 OCR 转写、文本清洗与归档分类规范，用于微调阶段文风模仿。

---

## 2. 执行规程

### 2.1 数据源识别
接收到参考语料时，确认其基本属性：
- **渠道平台**：X / 公众号 / 小红书等。
- **风格属性**：分享、整活+传播、技术+锐评、科普+干货等。
- **语料形态**：
  - **纯文本**：直接拷贝的博文或文章。
  - **图文混排（如小红书卡片）**：外层正文 + 图片内长图文。

### 2.2 图像 OCR 转写（针对图片内容）
若语料包含长图/卡片中的文字，按以下步骤处理：
1. 定位本地图片目录。
2. 调用 macOS Vision OCR 工具（`scratch/ocr`），对图片按文件名排序逐个执行转写，将结果输出：
   ```bash
   find "/path/to/images" -type f -name "*.png" | sort -V | while read img; do
     ./scratch/ocr "$img"
   done > scratch/ocr_raw_results.txt
   ```
   > 避免一次性处理过多图片，需使用上述 Shell 循环逐个执行。

### 2.3 文本清洗与修复
修复 OCR 识别出的错别字和冗余字符：
- **术语修正**：将 `1oop` 等修正为正确的 `Loop` 单词。
- **常见偏旁误识字修正**：将偏旁误读字（如 `钓`、`韵`、`时`）替换为正确的字义。
- **格式清理**：清除系统日志、分页符号和乱码。

### 2.4 文件规范化与保存
清洗完成后的文档平铺保存，格式要求：

#### YAML 元数据
开头必须包含 YAML Frontmatter，使用 `---` 包裹：
```yaml
---
title: 语料文章标题
platform: X / 公众号 / 小红书
style: 风格分类
source: 原始来源链接 (可选)
---
```

#### 小红书分割线规约
针对小红书外层博文与图片内详细长文共存的情况，必须使用专属分割线明确切分，以支持后续子技能提取：
```markdown
--- 📌 XHS_POST_TEXT_AND_DETAIL_DELIMITER 📌 ---
```
排版结构：
```markdown
---
title: 标题
platform: 小红书
style: 科普+干货
---

# 外层标题
外层博文文本...

--- 📌 XHS_POST_TEXT_AND_DETAIL_DELIMITER 📌 ---

### 图片转写详细标题
OCR 识别清洗后的图片长文内容...
```

#### 命名与路径
- **保存目录**：统一存放在技能的 `samples/` 目录下。
- **命名规范**：`platform_style_name.md`，使用小写与下划线（snake_case）。如 `xhs_lifestyle_loop_engineering.md`。

### 2.5 同步提示
写入完成后，告知用户文件名与路径，并提示执行手动同步指令以更新运行环境。
