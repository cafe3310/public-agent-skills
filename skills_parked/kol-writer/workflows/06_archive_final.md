# 子流程 06: 终稿归档 (Archive Final)

## 1. 目标
将微调确认后的大纲复制为终稿文件，输出创作总结并提供下一步建议。

---

## 2. 执行规程

### 2.1 复制生成终稿
将 `03-大纲草稿.md` 复制并写入同一工作目录下的 `03-大纲终稿.md`，执行以下处理：
- **清理已处理标注**：删除在微调阶段已解决的 `> 🔍 待调查` 与 `> 📊 待分析` 标记。
- **保留未决标记**：仍有争议或尚未处理的 `> ⚠️ 风险点` 与 `> ✏️ 待增补` 标记保留在终稿中，供撰写全文时参考。
- **写入头部元数据**：
  ```markdown
  ---
  创建时间: YYYY-MM-DD HH:mm
  主题: [大纲主题]
  目标平台: [目标平台]
  风格: [文风风格]
  版本: 终稿
  ---
  ```

### 2.2 输出创作总结与建议
文件写入后，向用户呈送归档总结：
```markdown
✅ 终稿已归档至：[目录名]/03-大纲终稿.md

### 创作总结

- **核心命题**：[提炼一句话核心观点]
- **大纲概要**：
  - [第一部分：核心点]
  - [第二部分：核心点]
- **遗留待处理项**：
  - [列出遗留的 ⚠️ 风险点 / ✏️ 待增补项]

### 下一步建议
1. 针对遗留的「待增补」标记，补充个人经历或一手案例。
2. 启动全文撰写，可参考 `rules/platforms.md` 进行文风调优与排版。
```

### 2.3 写作目录结构说明
工作流结束后，写作目录下包含以下文件：
```text
YYYY-MM-DD-{主题简述}/
├── 01-用户原始输入.md    # 创作初始参数（存档）
├── 02-用户想法记录.md    # 想法速记的原始对话（语料素材）
├── 03-大纲草稿.md        # 包含多轮微调历史的草稿
└── 03-大纲终稿.md        # 清洁版终稿（用于全文写作）
```
