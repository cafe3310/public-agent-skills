# 子流程 01: 初始化工作区 (Initialize Project)

## 1. 目标
工作流起点。Agent 提问收集创作任务参数，确认后创建独立的写作工作目录，保存原始输入。

---

## 2. 执行规程

### 2.1 收集任务参数
按以下五个维度依次提问，不要一次性抛出所有问题：
1. **主题**：本次创作的核心主题或论点。
2. **发布平台**：目标发布渠道（如小红书、公众号、X等）。
3. **文风风格**：希望呈现的风格（可参考特定博主，或由 Agent 建议）。
4. **读者目标**：期望读者阅读后产生什么反应或行动（如引发讨论、点击收藏等）。
5. **文风样例 (可选)**：是否有喜欢的参考文章、本地文件路径或历史作品。

> 用户回答不必完整，获取大概方向即可。若某项未定，提供 2-3 个建议或直接跳过。

### 2.2 信息确认
参数收集完成后，向用户确认：
```markdown
已确认创作参数：
- 主题：[输入值]
- 平台：[输入值]
- 风格：[输入值 / 待定]
- 目标：[输入值]
- 参考样例：[输入值 / 无]

确认无误后我将创建工作区，开始记录想法。
```
若用户提出修改，更新对应字段后重新确认。

### 2.3 创建工作目录与文件
确认后，执行以下操作：
1. **创建工作目录**：新建目录，命名格式为 `YYYY-MM-DD-{主题简述}/`。例如：`2026-06-25-大模型横评/`。
2. **保存原始输入**：在目录下创建 `01-用户原始输入.md`，写入以下内容：
   ```markdown
   ---
   创建时间: YYYY-MM-DD HH:mm
   ---
   
   # 用户原始输入
   
   - 主题：[输入值]
   - 目标平台：[输入值]
   - 风格：[输入值 / 待定]
   - 期望目标：[输入值]
   - 文风参考样本：[输入值 / 无]
   ```
3. **进入下一步**：告知用户工作区目录已创建，进入「观点速记」阶段。
