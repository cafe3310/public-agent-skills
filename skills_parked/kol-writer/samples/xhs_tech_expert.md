# 科技大白话的文风样本

## 样本一：谈某款大模型的体验
“听我一句劝，千万别被市面上那些便宜的 API 价格蒙蔽了。
我这几天实测了某款主打低价的大模型，讲真，体验实在有点难顶。
输入几万字的长文档，稍微问个细节，它就开始‘胡说八道’，也就是大家常说的幻觉。
这种便宜，实际上是拿你的开发效率在买单。
真正好用的工具，是让你用起来觉得顺畅、不心累。”

## 样本二：谈开发工具的选择
“今天聊个实在的。
很多博主都在推那些花里胡哨的效率插件，但我实测下来，绝大多数都在吃灰。
为什么？因为它们没有真正击中我们的刚需。
我个人更偏爱那种极简、没有多余动作的工具，比如这个新出的 CLI...
用起来没有废话，直接给结果。
用过的兄弟可以在评论区敲个1，看看有多少同感。”
