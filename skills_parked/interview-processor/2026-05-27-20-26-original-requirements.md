# 原始需求 (Original Requirements)

## 背景与问题说明

- **背景**：用户在进行招聘与面试管理时，积累了大量的面试原始数据（包括语音转写的面试记录、面试官的粗糙笔记、岗位 JD 和候选人简历）。为了能够对招聘质量进行结构化沉淀，同时评估和改进面试官的面试技能，需要一个自动化的工具/技能来处理这些数据。
- **提出的问题**：如何利用 Agent 技能自动化处理上述输入数据，并将处理结果结构化地输出到基于 `memories-off` 的本地知识图谱中。
- **为什么需要这份文档**：本科学归档了本技能的原始设计需求，以作为开发、测试以及后续优化的基础依据。

---

## 原始输入需求 (Original Requirements Copy)

以下为用户在 2026-05-27 20:25 提出的原始需求描述：

> 我们需要编写一个 agent skill. 
> 这个 agent skill 是用来处理面试记录的 --- 输入 {面试记录(语音转写), 面试官笔记, 岗位信息, 简历}, 输出 {标准化的报告, 本次面试官提出的问题, 对面试官的评价和优化建议} 到知识图谱。
> 这个 agent skill 需要（optionally) 配合 memories-off 这个 skill 使用。
