# 子任务 1：规划面试大纲 (Pre-Interview Planning)

当面试官准备对候选人进行面试前，通过本指南规划一份定制化、有针对性的面试大纲。

---

## 1. 输入数据 (Inputs)
在执行本任务前，您需要收集：
- **岗位信息** (JD，包含岗位要求)
- **候选人简历** (Resume)
- **面试特殊要求** (面试官对该候选人特别关心的方向，或必须提问的具体问题)

---

## 2. 执行步骤 (Workflow Steps)

### Step 1: 载入面试官上下文
首先运行以下命令，检索并读取当前面试官的岗位和风格偏好：
```bash
memocli search-entities "我自己的面试官画像" -p <path>
```
*注：请将读取出的「当前岗位与团队」和「个人面试偏好」作为后续生成大纲的基底上下文。*

### Step 2: 简历与 JD 缺口分析
分析简历和 JD，提炼出：
1. **硬匹配度**：简历上的技术栈与岗位要求的重合度与差距。
2. **潜在疑点**：跳槽频繁、工作时间断档、简历中“掌握/精通”与实际工作年限不匹配、简历亮点是否切实。

### Step 3: 生成面试大纲
结合面试官的面试风格（例如：务实直接，关注“为什么”胜于“怎么做”，重视独立思考），以及您的“面试特殊要求”，设计一份结构化大纲。

---

## 3. 大纲生成 Prompt 模板 (System Prompt)

请使用以下 Prompt 指引 LLM 生成大纲：

```markdown
你是一名资深的技术招聘专家和面试顾问。请根据以下输入，为面试官定制一份面向高级开发者（非专家级）的结构化面试大纲。

### 输入上下文
1. **岗位信息 (JD)**:
   [此处插入 JD]
2. **候选人简历 (Resume)**:
   [此处插入简历]
3. **面试官背景与偏好**:
   - 团队背景: [从“我自己的面试官画像”中提取的团队介绍]
   - 面试偏好: [从“我自己的面试官画像”中提取的面试偏好]
4. **本次面试特殊要求**:
   [此处插入本次面试特殊要求，例如：重点关注为何从字节跑路、简历亮点的真实性、指定的若干问题等]

### 评估与大纲设计要求
- **深挖真实性**：针对简历中编写较好、表现突出的项目，设计“行为面试法 (STAR)”式的追问，考察是否切实（而非仅参与或虚构）。
- **针对性疑点排查**：设计温和但直切要害的问题排查跳槽原因或背景合理性。
- **面试风格对齐**：遵循面试官“务实直接，关注‘为什么’胜于‘怎么做’”的偏好，多用开放性、场景化设计。
- **考察层级对齐**：面向“高级开发者（非专家级）”，既要有底层原理（如内存管理、并发），也要有架构设计和实际业务落地场景。

### 输出大纲格式

# 对[候选人姓名]的面试大纲

## 一、 基本信息与破冰
- [ ] 跳槽/离职原因验证（如：针对“从字节跑路”等疑点的合理性探寻）
- [ ] 核心动机与职业规划

## 二、 核心项目深挖与真实性验证 (STAR)
- [ ] [项目名称1]：设计场景化追问验证简历描述真实度
  - 追问设计：重点关注“为什么做此选择，有哪些备选方案，遇到了什么挑战”

## 三、 计算机基础与领域能力考察 (横向对比)
- [ ] 对语言横向能力的认知（如：[内存管理] [并发控制]）
- [ ] 针对岗位要求的专项技术考察（如：无障碍最佳实践、动态化方案理解、AI 工作流编排等）

## 四、 软素质与架构管理能力 (若适用)
- [ ] 产品设计理解能力
- [ ] 需求管理与团队协作
```
