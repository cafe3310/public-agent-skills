# 📖 给人类的安装介绍与说明

此 Skill 旨在为您提供一种极简的方式，将 **cafe3310** 开发的所有高效 Agent 技能（Skills）集成到您的本地环境中。

## 🌟 为什么需要这个？

通常，手动克隆仓库并逐个配置技能目录不仅繁琐，而且容易出错。通过这个 Installer，您可以：
- **一键全量安装**：自动下载并部署所有可用的技能。
- **无损静默更新**：随时同步最新的技能改进，而不会丢失您自己的自定义配置。
- **智能防冲突**：它会自动识别并跳过那些由您自己创建的同名技能。

---

## 🚀 如何开始？

您只需向您的 AI 助手（Agent）发送以下指令：

> **“请先读取并按此文件的指示进行操作： https://raw.githubusercontent.com/cafe3310/public-agent-skills/main/skills/cafe3310-skill-installer/SKILL.md”**

### 💡 为什么这么做？
通过这个 **Raw 链接**，您的 Agent 会直接读取经过优化的 `SKILL.md` 指令文件。它包含了 Agent 需要执行的所有具体步骤、权限设置以及安装脚本逻辑，能够确保 Agent 在不通过您干预的情况下，自主、精确地完成整个安装和更新流程。

---

## 🛠 脚本做了什么？

当您发起安装请求后，Agent 会在后台执行以下操作：
1. **获取源码**：从 GitHub 克隆最新的 `public-agent-skills` 仓库。
2. **扫描环境**：检查您本地的 `~/.agents/skills` 目录。
3. **安全同步**：
   - 发现属于 `cafe3310` 的技能：自动替换为最新版本。
   - 发现不属于 `cafe3310` 的同名技能：**跳过**并向您汇报，确保您的数据安全。
4. **生成报告**：最后为您列出一张清晰的表格，展示所有已就绪的技能及其用途。

---

## 📝 注意事项
- **网络连接**：由于需要从 GitHub 克隆仓库，请确保您的网络环境可以正常访问 GitHub。
- **权限要求**：您的 Agent 必须拥有执行 Bash 脚本的权限。
- **环境要求**：本脚本适用于 macOS 或 Linux 系统。
