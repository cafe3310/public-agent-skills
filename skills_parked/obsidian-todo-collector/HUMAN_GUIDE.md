# Obsidian 待办整理使用指南

本文档指导如何使用 `obsidian-todo-collector` 自动化汇总知识库中的未完成事项。

## 01. 快速开始

在 Obsidian 知识库中，使用类似这样的指令：

> 使用 `obsidian-todo-collector` 整理 [开始日期] 到 [结束日期] 的待办。

## 02. 工作流

这个 Agent Skill 会如下处理知识库中的文档：

1. 按文件名日期（`YYYY-MM-DD`）从小到大遍历文档。
2. 遇到大文件（>64KB/1000行）或「转写/摘录」类文档，Agent 会询问是否跳过（默认为跳过）。
3. 对未跳过的文件阅读全文，提取待办任务与规划，并汇总至 `📅 未完成事件整理.md`。
4. 汇总文档会实时标注「已处理」和「待处理」的文件链接，确保任务可断点续传。

最终会得到一份清晰的「未完成事件整理」文档，便于后续跟踪和管理。
文档中会以「宁滥勿缺」的思路记录待办，你可以按需使用。

## 03. 对知识库的要求

这个 Agent Skill 在日志式仓库中工作得最好。文档必须以 `YYYY-MM-DD` 或 `YYYY-MM-DD-hh` 开头，标记其创建日期。
待办和已完成事项最好用 `🟥`（待办）和 `🟩`（完成）进行状态识别与同步，没有也行。
