# 原始需求：Release Showcase Manager (模型发布演示管理器)

## 背景
用户需要一个 Agent Skill 来管理模型发布期间的大规模演示项目，范围涵盖从简单的网页生成、代码开发到复杂的工程项目、手机应用等。

## 核心需求
1. **工作区管理**：
   - 技能以特定目录作为工作区。
   - 工作区配置了 **Git LFS** 以管理大型素材。
   - 目录结构要求：
     - `docs-and-ref/`：文档与参考资料（输入与输出）。
     - `notes/`：记录开发笔记、模型观察与评价（输出）。
     - `showcases/`：包含多个子目录，每个子目录为一个具体的演示项目（输出）。
     - `video-raw/`：存放原始录屏素材（输出）。
     - `video-clipped/`：存放裁剪后的成品视频（输出）。

2. **状态管理**：
   - 依赖 `doc-todo-log-loop` 技能实现断点续传，确保长期任务的持续性。

3. **工作流程 (循环模式)**：
   - **阶段 1：发现与收集**：收集模型信息、素材和参考资料。
   - **阶段 2：方案设计**：设计开发任务和演示场景。
   - **阶段 3：执行开发**：进行具体的开发工作（代码、网页、应用等）。
   - **阶段 4：录制与记录**：在开发过程中录制视频并同步记录笔记。
   - **阶段 5：评价与洞察**：输出对模型的观察、判断与评价。
   - **阶段 6：最终产出**：输出裁剪后的成品视频。

4. **演示多样性**：
   - 支持网页生成、代码工程、移动端应用等多种类型的演示。
