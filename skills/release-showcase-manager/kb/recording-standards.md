# AI Showcase 录制与视觉规范 (Recording & Visual Standards)

为了实现“Luxury Tech”（如 Linear, Stripe, Apple 风格）的极致视觉质感，本规范定义了录屏、UI 适配及视觉呈现的标准。

## 1. 核心参数 (Technical Specs)

*   **分辨率 (Resolution)**: 
    - 录制时：**必须使用 4K (3840x2160)**。即使最终输出是 1080p，4K 也允许我们在不损失像素的情况下进行 200% 的局部无损放大。
    - 输出时：1080p 或 4K。
*   **帧率 (Frame Rate)**: 
    - 建议使用 **60 FPS**。高帧率不仅能使动作更流畅，也为后期变速处理提供了更大的空间。
*   **屏幕比例 (Aspect Ratio)**:
    - **16:9**: 主流网页、YouTube、官网演示。
    - **9:16**: 移动端 App 展示、TikTok/Shorts。
    - **1:1 或 4:5**: Twitter/LinkedIn 动态流。

## 2. UI 适配与缩放 (Optical Balance)

为了让界面在视频中显得“丰满”且易读，严禁直接以 100% 原始缩放录制：
*   **系统级缩放 (OS Scaling)**: 将操作系统缩放倍率调整至 **200%**。这会使按钮、图标和字体显得更大、更具“质感”。
*   **浏览器级缩放 (Browser Zoom)**: 如果录制 Web App，建议将浏览器缩放至 **125% - 150%**。
*   **窗口布局**: 
    - 去除所有不必要的 UI 噪音：隐藏浏览器书签栏、侧边栏、系统菜单栏（Menu Bar）和 Dock。
    - 推荐使用 **Arc 浏览器** 的“清爽模式”。

## 3. 字体与排版 (Typography)

选用具备“专业感”和“现代感”的无衬线字体：
*   **首选字体**:
    - **Inter**: 现代、紧凑，尤其适合数据和代码较多的应用（Linear 风格）。
    - **SF Pro (San Francisco)**: 苹果原生质感，极其克制、专业。
    - **Helvetica Now**: 经典的瑞士设计风格。
*   **字重与间距**:
    - 标题建议使用 **Semi-Bold**。
    - 正文建议使用 **Regular**。
    - 严格禁止使用 Thin 或 Light 字重，这些在移动设备小屏幕上会变得难以识别。

## 4. 录制动效规范 (Motion & Cursor)

*   **光标路径 (Cursor Path)**:
    - 避免人类那种细碎、抖动的光标移动。
    - 推荐使用 **Screen Studio** 等工具自动平滑光标轨迹，使其呈 S 型曲线滑动。
*   **“呼吸感”停顿**:
    - **点前停顿 (Pause-Before-Click)**: 光标移动到目标位置后，停顿 0.5 - 1 秒再点击。
    - **点后停留 (Pause-After-Click)**: 点击动作完成后，停留 1 秒让观众消化结果，再进行下一步操作。
*   **变焦与跟拍 (Zoom & Follow)**:
    - 仅针对当前正在讨论或点击的局部区域进行平滑变焦（Ken Burns 效果）。
    - 保持视觉焦点始终在屏幕中心或黄金分割点。

## 5. 背景与环境 (Environment)

*   **极简背景**: 录屏背景建议使用深色（如 `#000000` 或 `#0B0B0B`），可带有极淡的紫色或青色光晕（Glow）。
*   **圆角与阴影**: 演示窗口应具备大半径圆角（如 `24px`）和柔和的长阴影（Soft Drop Shadow），增加空间深度感。
*   **数据脱敏**: 严禁使用“Test 1”等垃圾数据。使用具有真实感、高质量的模拟数据，使演示看起来像是一个真实运行的成熟产品。

## 6. 推荐工具链 (Recommended Tools)

*   **Screen Studio (macOS)**: 最佳推荐。自动平滑光标、动态缩放、内置 Luxury 背景。
*   **Arc Browser**: 清理网页录制环境。
*   **Figma**: 用于制作转场封面和标注图。
