# 技能：线上素材收集器

## 概述

此技能旨在帮助用户（cafe3310）构建一个持久化的本地素材库。它通过自动化工作流，定期处理 Obsidian 中的“待本地化链接”，将线上内容（如推文、文章、视频、灵感图）抓取并转化为本地 Markdown、HTML 或视频文件。

**关键词**: 素材收集, 网页归档, yt-dlp, 视频下载, Obsidian 联动

## 核心流程

1.  **读取任务**: 扫描 Obsidian 仓库中的 `待本地化素材链接库.md` 文件。
2.  **链接提取**: 提取文件中的 URL 及其关联的备注信息。
3.  **分类下载**:
    - **视频类**: 使用 `yt-dlp` 下载最高画质，并嵌入元数据。
    - **网页/文章**: 使用 `MarkItDown` 或 `Pandoc` 转换为包含 Base64 图片的 Markdown 文件。
    - **灵感图/画廊**: 使用 `gallery-dl` 或专用脚本抓取。
4.  **归档整理**: 将素材存入已归档目录，并按照 `{YYYYMMDD}_{来源}_{标题}` 规范命名。
5.  **状态更新**:
    - 成功：将链接移动至 `已经本地化素材.md`。
    - 失败：将链接及错误信息移动至 `需要手动处理.md`。

## 工具链要求

- **yt-dlp**: 用于视频下载。
- **Pandoc / MarkItDown**: 用于网页转 Markdown。
- **SingleFile-CLI**: 用于完整网页 HTML 归档。
- **ffmpeg**: 用于音视频合成。

## 最佳实践

- **静默处理**: 批量处理时优先使用静默模式，减少日志噪音。
- **断点续传**: 处理大型视频时，记录进度以支持重试。
- **元数据保留**: 在 Markdown 头部（Frontmatter）记录原始 URL、抓取日期及用户备注。
- **画质优先**: 视频下载默认请求最高画质。
