# cafe-whatabout

检索 Obsidian 知识库中关于目标项目的最新记录（优先读取 Jira、TODO、设计文档和近期纪要），输出极简项目进度汇总。严格控制在以下 5 个部分，每部分不超过 3 条，省略背景铺垫：

1. **目标与交付物**：一句话目标 + 当前核心交付物 + 关联方交付物（若有）
2. **关键时间线**：列出接下来最关键的 3 个时间节点
3. **当前现状**：按模块用 2-3 句话说明已完成和进行中的事实
4. **上下游依赖（外部阻塞 vs 对外交付）**：
   - 外部阻塞：依赖的前置条件、外部模块或待确认事项
   - 对外交付：下游模块或协作方等待我方提供的产出及节点
5. **主要风险与下一步**：当前最大的进度风险 + 接下来需要立即执行的 1 件事
