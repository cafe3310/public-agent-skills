# 内容语气调整

## 描述

此技能旨在帮助 Agent 对既有文本或文档进行深度的风格和语气调整。

当前，它集成了四种常用的文本调整方向：

1. **cafe3310 的移除 AI 常用滥用表达风格**：侧重于消除 AI 生成文本中的套路化表达、过度奉承、长难句和刻板的机器感，让行文更像人类自然写的散文或博客。
2. **移除大词风格**：侧重于去除职场「大词」「黑话」与「宏大叙事」，将浮夸修辞转化为低调、务实、平实的操作性语言。
3. **hexiecs 的极简直白风**：侧重于极度精简、直接断言、不绕弯子、拒绝正反对比句式和总结性套话，适合快速问答、技术解答或核心观点输出。
4. **学术研究风（去公司战役感）**：侧重于利用「公司战役」与「学术研究」的对立特性，清除拟人、比喻、战斗风格用语与激情修辞，直接陈述事物本质，保持客观中立的研究与工程范式。

## 工作流

当用户激活或使用此技能时，请严格按照以下步骤执行：

### 第一步：询问调整意向与加载过往经验

1. **询问语气方向与细节偏好**：
   若用户未在初始 Prompt 中明确指定以下参数，需询问或使用 `ask_question` 工具确认：
   - **语气风格方向**：
     1. cafe3310 的移除 AI 常用滥用表达风格
     2. 移除大词风格
     3. hexiecs 的极简直白风
     4. 学术研究风（去公司战役感）
   - **Markdown 格式处理**：是否要一并移除过多的 MD 加粗/列表格式（例如将 `- **Point A**: explain A` 简化为 `- Point A, explain A`）？
   - **篇幅控制**：是保持原有文字量与细节丰富度？还是对文字内容一并进行精简？

   **注意：在此处必须等待用户确认偏好。在参数确定之前，不要进行任何文本处理。**
2. **参考过往经验**：在加载提示词前，Agent 必须主动检索并读取 `skills/content-tone-adjuster/experiences/` 目录下的 `.diff` 文件。提取出与当前任务所选风格相同、或所改文件类型相似的历史修改示例（包含 YAML 头部中的用户意图），作为 few-shot 对照载入 Context 中，确保新修改契合用户的历史偏好。

### 第二步：加载对应系统提示词

根据用户的选择，使用文件读取工具加载对应的规则提示词：
- 如果用户选择“1”或“cafe3310 的移除 AI 常用滥用表达风格”，请读取文件：`skills/content-tone-adjuster/remove-ai-artifacts/prompt.md`
- 如果用户选择“2”或“移除大词风格”，请读取文件：`skills/content-tone-adjuster/grounded-writer/prompt.md`
- 如果用户选择“3”或“hexiecs 的极简直白风”，请读取文件：`skills/content-tone-adjuster/talk-normal/prompt.md`
- 如果用户选择“4”或“学术研究风（去公司战役感）”，请读取文件：`skills/content-tone-adjuster/academic-research/prompt.md`

### 第三步：执行调整与审查反馈

1. 结合系统提示词与读取的 `.diff` 历史经验，使用编辑工具对文本执行手术式精准修改（禁止大范围完整重写）。
2. 修改完成后，**必须输出当前修改的 git diff 差异，并向用户提问**：“这是本次修改的 diff，请问您是否满意？”。
3. 若用户不满意，根据用户的进一步反馈进行微调，直到用户满意为止。

### 第四步：积累过往经验（若满意）

一旦用户确认满意：
1. 运行 `date` 获取当前时间（格式为 `YYYY-MM-DD HH:mm`）。
2. 提炼用户此次的指示概要（格式为：“对什么东西，做什么调整，以实现/避免什么”）。
3. 提取本次满意的 `git diff` 内容，进行规范化保存。
   **重要（工作文档脱敏规范）**：如果是工作文档，保存的 `.diff` 必须进行脱敏与句式提取：
   - 截取少数几条最具代表性的改写行；
   - 用省略号 `...` 物理替换掉具体的公司、项目、任务参数、数字等专有信息，仅保留能体现“大词长难句”向“直白平实陈述”演变的**句式结构对比**。
4. 配上统一的 YAML Frontmatter：
   ```yaml
   ---
   date: YYYY-MM-DD HH:mm
   user_instruction: "用户的指示概要"
   style: "cafe3310 的移除 AI 常用滥用表达风格 / 移除大词风格 / hexiecs 的极简直白风 / 学术研究风（去公司战役感）"
   ---
   diff --git ...
   ```
5. 将该内容物理保存为 `skills/content-tone-adjuster/experiences/date-hour-{type}-{tone}.diff` 文件。其中：
   - `date-hour` 格式为 `YYYY-MM-DD-HH`；
   - `{type}` 必须为 `brief`（省略 diff，只保留句式结构对比）或 `normal`（完整 diff，保留具体事实和细节）；
   - `{tone}` 为修改的简要说明。
   用以积累和固化用户的偏好。
