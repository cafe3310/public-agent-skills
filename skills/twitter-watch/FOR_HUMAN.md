# 📖 Twitter 互动数据监控 (twitter-watch) 使用指南

这个技能专门为您解决：**如何高效、真实地获取多条推文的互动指标（查看、回复、转发、喜欢、书签）。**

通过这个技能，您可以让 Agent 模拟真人操作，在您的本地浏览器中自动访问推文并提取最精确的数据，包括网页端通常难以批量统计的“书签数”。

---

## 🌟 核心能力

- **全量指标提取**：获取查看次数、回复数、转发数、喜欢数以及珍贵的“书签数”。
- **拟人化防封**：模拟真人的滚动和停留行为，极大降低被平台风控的风险。
- **登录状态复用**：自动复用您本地 Chrome 的登录状态，确保能看到登录后才可见的详细数据。
- **自动汇总报告**：抓取完成后，自动为您生成一份精美的 Markdown 表格报告。

---

## 🚀 如何开始使用？

您只需要按照以下简单的三步操作即可：

### 1. 开启 Chrome 远程调试（关键步骤）
为了让 Agent 能够控制您的浏览器，需要先开启调试模式：
1. **打开配置页面**：在 Google Chrome 浏览器的地址栏输入 `chrome://inspect/#remote-debugging` 并按回车。
2. **确认配置**：确保页面上的 **"Discover network targets"** 选项已被勾选。
3. **点击允许**：如果页面弹出询问是否允许远程调试的提示，请点击**“允许”**。
4. **过程提醒**：在 Agent 执行任务期间，如果 Chrome 再次弹出任何请求允许远程连接的对话框，请务必点击**“允许”**，否则抓取会失败。

### 2. 准备链接文件
在您的电脑上创建一个普通的文本文件（比如 `links.txt`），把您想查看的所有 Twitter 链接放进去，**每行一个链接**。

### 3. 把文件路径告诉 Agent
在对话框中直接把文件的位置发给 Agent，例如：
> **“帮我监控一下这个文件里的推文数据：`/Users/yourname/Desktop/links.txt`”**

---

## 🛠 常见问题排查

如果您遇到“无法连接浏览器”的错误，请尝试：
- 再次确认 `chrome://inspect/#remote-debugging` 中的勾选状态。
- 重启 Chrome 浏览器后再次尝试。

---

## 🛠 注意事项（重要）

1. **浏览器配合**：为了确保抓取成功，Agent 在启动时可能会在您的电脑上打开一个 Chrome 窗口。如果浏览器上方出现“允许远程调试”之类的提示，请点击**允许**。
2. **账号安全**：本技能仅在您本地运行，不会上传您的 Cookie 或账号信息到任何云端。
3. **数据准确性**：由于 Twitter 的反爬虫机制，建议一次抓取的链接数量不要过多（如超过 50 条），以免触发频率限制。
