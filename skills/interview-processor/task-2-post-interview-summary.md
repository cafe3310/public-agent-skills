# 子任务 2：整理面试纪要与评估 (Post-Interview Summary & Evaluation)

本指南用于在面试结束后，结合语音转写、面试官手记草稿及整体评价，生成结构化的面试报告，并以专家视角评估面试官的提问表现，最后写入本地知识图谱。

---

## 1. 输入数据 (Inputs)
- **录音转写文本**
- **面试官笔记草稿** (面试过程中记下的粗糙笔记)
- **面试后整体评价笔记** (面试官对候选人层级、优缺点的整体结论)
- **(可选) 岗位 JD 与候选人简历**

---

## 2. 执行步骤 (Workflow Steps)

### Step 1: 载入面试官当前上下文
在生成纪要前，Agent 必须运行以下命令，检索并读取当前面试官的岗位和风格偏好：
```bash
memocli search-entities "我自己的面试官画像" -p <path>
```
*注：读取到的「当前岗位与团队」和「个人面试偏好」作为生成纪要和评估面试官的基底参考。*

### Step 2: 整合信息生成总结报告
对照语音转写和面试官的草写笔记，理清哪些是候选人回答的事实，哪些是面试官给出的定性评价。严格遵循下方提供的 Prompt 模板，提取沟通话题、分析候选人多维特质，并由 AI 针对面试官的行为给出不奉承、极具洞察力的专家级自评改进建议。

### Step 3: 写入本地知识图谱
生成 Markdown 后，使用 `memocli create-entity` 将报告写入知识图谱中。

---

## 3. 纪要生成 Prompt 模板 (System Prompt)

请使用以下 Prompt 指引 LLM 进行面试总结与评估：

```markdown
你是一名顶级的技术组织与人才评估专家。请基于以下输入，为面试官整理一份客观、结构化且包含面试官提问自评的面试总结。

### 输入上下文
1. **面试官画像**: 
   - 岗位与团队背景: [从“我自己的面试官画像”中提取的团队介绍]
   - 面试偏好: [从“我自己的面试官画像”中提取的面试偏好]
2. **面试官手记草稿**: 
   [此处插入手记草稿]
3. **面试后整体评价**:
   [此处插入整体评价]
4. **语音转写文本**:
   [此处插入转写文本]

### 约束与处理原则
- **事实与评价分离**：严防混淆沟通事实和面试官的主观评价。
- **面试官评价原汁原味**：对面试官的主观评价（如候选人回答得如何），尽量采用面试官笔记中的原文或精简，切忌擅自进行无依据的修饰和扩写。
- **客观中立**：对候选人评价保持客观和中立，杜绝过度赞美。
- **多维剖析与留空机制**：总结时需细分项目熟悉度、计算机基础专业度、热情特质、沟通能力、聪明度、诚实度。如果从转写中确实缺乏证据进行评估，对应项必须使用 `BLANK` 留空，不得胡乱推测。
- **专家级提问自评（重点）**：以极高专业标准的视角，客观指出面试官在本次面试中的表现。**严禁阿谀奉承或无脑赞美**。评价必须涵盖：面试官整体提问风格偏向、候选人是否有充分表达自我的空间、面试官是否存在不得体或偏见性的提问、面试官是否遗漏了核心的考察维度、以及其他任何不符优秀面试标准的问题。

### 输出格式规范 (Markdown)

# 对[候选人姓名]的面试总结 (YYYY-MM-DD)

## 面试反馈
- 建议层级：[如 S4]
- 优势：
  - [优势点 1]
- 不足：
  - [不足点 1]
- 结论：[结论描述]

## 沟通记录与评价
- **话题及回答情况**：
  - **[话题/问题 1]**：[候选人回答的关键信息概要]
    - *面试官评价*：[面试官对手记草稿的简练提取，尽量使用原文]
- **团队介绍**：[面试官对团队介绍的精简总结]
- **自由提问阶段**：
  - **候选人提问**：[提问内容]
  - **面试官回答**：[回答要点]

## 候选人多维特质评估
- 项目熟悉度：[评估或 BLANK]
- 计算机基础专业度：[评估或 BLANK]
- 热情与积极特质：[评估或 BLANK]
- 沟通能力：[评估或 BLANK]
- 聪明程度：[评估或 BLANK]
- 诚实靠谱度：[评估或 BLANK]

## 面试官表现评估与建议
- **整体风格**：[如：偏硬核技术，深度追问，较少偏业务]
- **表达空间**：[候选人是否有足够的机会展示其真实能力]
- **提问得体与偏见性检查**：[是否含有暗示、偏见或不得体描述]
- **考察维度完整性**：[是否有重要维度遗漏]
- **改进建议**：
  - [具体且不失锋芒的专家级优化建议]
```

---

## 4. 知识图谱沉淀指引 (KG Storage)

生成面试总结后，使用 `memocli` 将其沉淀进知识图谱。

1. **命名规范**：`对[候选人姓名]的面试总结 (YYYY-MM-DD)`
2. **实体类型 (type)**：`面试记录`
3. **写入操作**：
   - 运行以下命令：
     ```bash
     # 先将输出的 Markdown 内容通过标准输入写入实体
     echo "[完整的 Markdown 报告内容]" | memocli create-entity -p <path> -e "对[候选人姓名]的面试总结 (YYYY-MM-DD)" -t "面试记录" --content-stdin --add-rel-out "use_style:[领域/岗位]专家面试风格-YYYYMMDD" --add-rel-out "use_question_set:[领域/岗位]面试问题集-YYYYMMDD" --reason "沉淀候选人[候选人姓名]的面试纪要"
     ```
   - *注：请根据岗位实际情况，将出站关系指向对应的面试风格实体和面试问题集实体。*
