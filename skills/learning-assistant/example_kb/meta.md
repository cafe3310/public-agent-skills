# Knowledge Base Manual (meta.md)

## 1. 概述 (Overview)
这是名为 `Zig学习库` 的知识库手册，遵循 memories-off 规范。本知识库由 memories-off 库和 learning-assistant (学习助手) 技能共同创建。

## 2. 核心 Schema (Core Schema)
### 实体类型 (Entity Types):
- 项目
- 状态
- 学习日志
- 学习主题
- 学习计划
- 资料
- 概念

## 3. 命名与编辑准则
- 实体命名：**文件名即实体名** (例如 `cafe3310.md`)。
- 实体类型：由 `entity type` 元数据指定。
- 关系值规范：使用实体名称（WikiLinks `[[实体名]]` 或显式关系 `relation as ...`）。
