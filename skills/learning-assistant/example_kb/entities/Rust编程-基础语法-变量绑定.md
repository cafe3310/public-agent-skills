# Rust编程-基础语法-变量绑定

## 概念详解
Rust 使用 `let` 关键字绑定变量，变量默认是不可变的（immutable）。若需可变，需使用 `mut` 关键字。

## 学习过程整理
讲解了 Rust 变量绑定以及可变性的原理（包括隐藏机制 Shadowing）。用户理解良好，完成了对 shadowing 和 mut 的对比练习。
