# Rust编程-所有权机制-借用与引用

## 概念详解
引用（Reference）允许在不获取所有权的情况下使用值。借用（Borrowing）指将引用作为参数传递给函数。遵循核心规则：同一时间只能有一个可变引用或任意多个不可变引用，且引用必须始终有效。

## 学习过程整理
系统讲解了不可变借用与可变借用不能共存的编译器法则。通过对借用检查器（Borrow Checker）典型报错的修复练习，用户掌握了生存期的基本边界。
