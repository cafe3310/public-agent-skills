# 微服务架构-Docker基础-镜像与容器

## 概念详解
镜像是 Docker 运行的静态只读模板，包含运行容器所需的所有文件系统和运行参数；容器则是镜像运行时的实体，是独立且受隔离的进程空间。

## 学习过程整理
引导讲解了什么是 UnionFS 以及镜像分层概念。用户提问了关于“容器内数据持久化”的问题，已引导用户了解 Docker Volume 数据卷的相关机制，并完成了随堂测试。
