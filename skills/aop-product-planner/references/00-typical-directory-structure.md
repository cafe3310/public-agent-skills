# 典型的项目产出目录结构规范 (Typical Directory Structure Spec)

│   │   ├── D10-项目背景与定位总览.md

## 文件名与编号规范 (Filename Conventions)

1. **单级大类编号 (Dxx Block)**：
   * 所有目录与模块统一使用字母 `D` 叠加 2 位数字大类编号标识（如 `D10` 叙述、`D20` 目标、`D30` 切面、`D40` 需求、`D50` 参考产品）。
2. **参考功能点编号 (D52-nnnn Block)**：
   * 参考产品细粒度功能点（在 `D52-功能点列表/` 下）使用 4 位递增数字编号：`D52-nnnn-简述.md`（例如 `D52-0001-模型选择.md`、`D52-0002-工具配置.md`）。
   * 编号按记录或梳理顺序依次递增。
3. **干净 WikiLinks 引用**：
   * 文档间引用统一采用带编号的 WikiLinks 格式 `[[文件名]]`（无扩展名与包裹反引号）。
