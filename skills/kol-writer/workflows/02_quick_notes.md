# 子流程 02: 观点速记 (Quick Notes)

## 1. 目标
记录用户在自由谈话中提出的想法与观点。保留原始口语表达，作为后续大纲整理与文风模仿的语料基础。

---

## 2. 执行规程

### 2.1 最小反馈原则
- **只记不推**：用户输入可能零碎且跳跃。Agent 仅对发言做简短确认（如「明白，已记录关于……的想法」），**严禁**主动推理、重构逻辑或提供方案。
- **澄清追问**：仅在语义极其模糊、影响基础记录时进行简短确认，避免打断用户思路。

### 2.2 实时追加记录
将用户对话中的原始输入（包括口语化表达与随笔）追加保存至工作目录下的 `02-用户想法记录.md`。格式如下：
```markdown
# 原始想法记录

- **用户输入 1**：[原始文本]
- **用户输入 2**：[原始文本]
```

### 2.3 结束判定
当用户发出结束信号（如「说完了」、「开始整理吧」），Agent 停止记录，保存并关闭 `02-用户想法记录.md`，确认并进入下一阶段。
