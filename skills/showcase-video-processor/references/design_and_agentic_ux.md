# 高级设计美学与智能体交互 (AX) 规范

本指南旨在为模型演示提供最前沿的视觉与交互参考，涵盖“Luxury Tech”审美、智能体经验（AX）以及 3D 架构可视化。

## 1. Luxury Tech 审美 (高级感软件设计)

这种风格（也称为“Linear 风格”或“宁静奢华”）已成为高精尖 AI 产品的标配。

### 核心视觉元素
*   **深色底色:** 使用深木炭色 (`#0B0B0B`) 或真黑，而非深蓝或普通灰色。
*   **发丝边框 (Hairline Borders):** 0.5px - 1px 的超细边框，配合极细的渐变色，模拟光线打在金属边缘的效果。
*   **Bento 布局:** 模块化的圆角容器，将复杂的数据结构组织成整洁、易读的方块。
*   **微动作 (Micro-motions):** 极高帧率的小型过渡（如鼠标悬停时边框微弱亮起），传递“精密工业品”的感觉。
*   **氛围光晕:** 模糊的彩色光影（Streamers），暗示 AI 的能量流动，而非生硬的霓虹灯。

## 2. 智能体经验 (Agentic Experience, AX)

在 2026 年，设计重点已从“帮助用户操作”转向“帮助用户委托目标并评估结果”。

### 核心原则
*   **从 UX 到 AX:** 解决“评估鸿沟”。用户关心的不是 AI 怎么做，而是 AI 做得对不对。
*   **生成式 UI (GenUI):** UI 不再是预设的，而是根据任务实时生成的。例如，AI 需要你审批预算时，才生成一个临时的“审批卡片”。
*   **共享自主权:**
    *   **观察模式:** 实时观察 Agent 的思考路径。
    *   **协作模式:** Agent 提议，用户确认。
    *   **自主模式:** Agent 运行，只在结果完成或遇到阻碍时汇报。
*   **可视化思考过程:** 通过垂直步骤列表和“信心指数”展示 Agent 的计划 vs 完成情况。

## 3. 3D 模型架构可视化

通过将抽象的模型逻辑转化为 3D 视觉元素，增强演示的说服力。

### 可视化隐喻
*   **分层堆栈:** 将模型的每一层（卷积、池化、全连接）表示为一个 3D 平面或方块。
*   **权重连接线:** 使用线条粗细或颜色（蓝色正向，橙色负向）表示权重的强度。
*   **激活状态展示:** 使用 Three.js 展示数据流过层级时的“激活图”，让模型“思考”过程肉眼可见。

### 推荐技术栈
*   **TensorSpace.js:** 专门用于在浏览器中渲染 3D 神经网络架构。
*   **React Three Fiber:** 将 Three.js 的 3D 能力与 React 的状态管理完美结合。
