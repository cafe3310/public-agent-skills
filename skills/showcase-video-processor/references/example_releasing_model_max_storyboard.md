# Releasing-Model-Max 演示视频详细分镜脚本

概述

基于多段录制的模型演示素材，提出四个部分的视频展示方案。
本分镜脚本旨在通过对素材的精确拆解，指导后续的视频剪辑与后期合成。

---

## 通用演示规范：输入-生成-结果
为了保持整体视频的紧凑感 and 专业度，所有涉及“输入-生成-结果”的环节均遵循以下标准（每个 ~7s）：

1. **Phase 1: Input (2s)**
   - **视觉**：Zoom in 聚焦输入框，镜头随光标输入位置平滑移动。
   - **节奏**：展示字符流出感，在指令输入完成后定格 0.5s，让观众看清 Prompt.
2. **Phase 2: Generation (Max 2s)**
   - **视觉**：保持中景或全景，展示内容逐行或逐块蹦出的动态。
   - **节奏**：进行 3x - 10x 倍速快进。
3. **Phase 3: Result (3s)**
   - **视觉**：
     - **长文本**：放大文字区域，平滑向上滚动展示全文。
     - **网页/UI**：进行页面从顶层到底层的平滑滚动展示。
   - **节奏**：展示结果的完整性，结尾处定格，淡出至下一分镜。

---

## 多样性展示分镜：三拼展示
用于同时展示多个风格或体裁，体现模型的灵活性（Total: ~4s）：

1. **布局**：三个视频窗口（1:1:1）横向并列，窗口间留缝隙
2. **启动**：同时启动。
3. **标注**：各窗口上方悬浮具体的风格标签（如：[ 幽默 ]、[ 技术 ]、[ 诗歌 ]）。
4. **收尾**：三个窗口在生成结束后同时定格，展示最终对比画面。

---

## 集合展示规范：交错滚动
专门用于网页或设计稿的多样性展示，展现模型输出风格的丰富度与质量（Total: ~4s）：

1. **布局**：将多张设计截图以 3 列或 4 列的瀑布流（Masonry）形式拼接成一整张大画布
2. **动效**：
   - **交错滚动**：不同列以不同方向滚动（上/下/上/下这种）。让原本静态的网页截图“活”起来。
3. **收尾**：滚动平滑切出。

## 第一部分、网页和设计生成

> **本节主旨**：Releasing-Model-Max-2.6-1T 能够快速、精准地生成大量高质量前端代码。在处理丰富交互与 UI 设计时，模型不仅展现出极强的逻辑实现能力，更具备出色的“AI 审美”，能够根据指令精美、灵动地呈现出各种设计风格。
> 
> **在这个例子中**，我们将展示模型如何通过简单的指令迅速生成一套完整的网页前端（如 UI 组件生成），并随后利用交错滚动的视觉效果，一览模型在生成诸如工业风、拟物化等多样化设计风格时的卓越表现。

### 分镜 1.1：从输入到完整网页

- **素材名称**：`04-releasing-model-max-1t-web-gen-2_1.mov`
- **素材拼接方式**：顺序播放。遵循「输入-生成-结果循环」规范。
- **[素材内容分析]**：
  - `04-releasing-model-max-1t-web-gen-2_1.mov`: 展示网页 UI 的生成过程。
- **内容描述**：
  - **0s-2s (输入)**：画面 Zoom in 聚焦代码/指令输入区。跟随光标移动，定格 0.5s。
  - **2s-4s (生成)**：Zoom out 恢复全图。生成画面进行 5x 倍速非线性快进。
  - **4s-7s (结果)**：恢复 1x 原速。向下平滑滚动已渲染完成的网页，展示排版与动效细节。定格 1s 后硬切。

### 分镜 1.2：设计多样性展示

- **素材名称**：`releasing-model-max-1t-web-gen-slide.zip` 中的多张网页截图（如 `art-deco-stock`, `gallery-style`, `nordic-wood` 等）。
- **素材拼接方式**：遵循「交错滚动 (Staggered Scroll Collection)」规范。
- **[素材内容分析]**：
  - `PNG 集`: 包含多种风格鲜明的前端页面截图，如装饰艺术风 (Art Deco)、拟物化 (Neumorphism)、工业风 (Industrial)、极简木质风 (Nordic Wood) 等。
- **内容描述**：
  - **0s-1s**：画面切入，展现瀑布流排布的网页截图画布集合。画面微微放大。
  - **1s-4s**：各个截图交错向上/向下滚动。
