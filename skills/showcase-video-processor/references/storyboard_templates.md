# 演示视频分镜模板 (Storyboard Templates)

本指南提供三种针对不同场景的模型演示分镜模板，帮助团队快速构思视频结构。

## 1. 经典 SaaS/功能导向型 (Feature-Focused)
适用于展示特定的工具或插件，强调“点击即所得”。

| 场景 | 视觉画面 | 音频/旁白 | 表达重点 |
| :--- | :--- | :--- | :--- |
| **1. Hook** | 用户面对凌乱的原始数据或空白的编辑器，露出困惑表情。 | "还在为处理海量数据而头疼吗？" | 痛点共鸣 |
| **2. Intro** | Logo 动画 + 简洁的产品主界面全景。 | "遇见 [产品名]，由 AI 驱动的分析平台。" | 建立品牌 |
| **3. Feature A** | 录屏：用户点击“生成”，AI 瞬间产出图表。 | "只需提问，我们的 AI 即可为你构建图表。" | 核心能力 A |
| **4. Feature B** | UI 特写：点击“预测”开关，显示趋势预测。 | "一键预测未来趋势，快人一步。" | 核心能力 B |
| **5. Outcome** | 成功的状态：满意的用户，或“节省 10 小时”的文字。 | "将数小时的手动工作转化为秒级的洞察。" | 价值量化 |
| **6. CTA** | 屏幕显示 URL + "开始试用" 按钮。 | "立即访问 [网址] 开启你的智能之旅。" | 行动指引 |

## 2. 叙事/情感共鸣型 (Narrative/Emotional)
适用于 AI 原生产品，强调 AI 带来的“魔法感”和创造力释放。

*   **场景 1: 灵感闪现。** 展现一个创意火花（如随手画的草图）。
*   **场景 2: 魔法转化。** 展现模型如何根据草图生成精美的 3D 模型或视频。
*   **场景 3: 极致个性化。** 展现模型根据用户反馈实时调整，呈现出无数种可能性。
*   **场景 4: 创作者赋能。** 重点不再是工具，而是创作者脸上的惊喜和成就感。

## 3. 开发者/深科技型 (Developer/Deep-Tech)
适用于展示基础模型、API 或 IDE 插件。

*   **场景 1: 复杂代码块。** 展示一段难以理解的代码或复杂的 bug。
*   **场景 2: Copilot 介入。** 展现流式生成的代码补全或清晰的 bug 修复建议。
*   **场景 3: 性能看板。** 展现模型在 Benchmark 上的优异表现或极低的推理延迟。
*   **场景 4: 实际部署。** 展现模型在真实生产环境中的稳定运行。

## 关键视觉策略
*   **智能缩放 (Smart Zoom):** 不要总是展示全屏，在讲解特定按钮或代码行时，进行局部放大。
*   **视觉标注:** 使用高亮的框、箭头或半透明的浮层来引导观众的视线。
*   **人机并排:** 在屏幕的一角展示真人（或 AI 数字人）的反应，增强真实感和信任感。
