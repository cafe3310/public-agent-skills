# 工作流 03：多粒度分镜策划 (Storyboard Planning)

## 目的
根据演示目标，将初稿素材组织成逻辑严密、视觉统一的分镜稿，为最终合成提供蓝图。

## 输入
*   `draft_assets/` 目录下的初稿素材。
*   用户对演示目标的描述（如：模型 A 与 B 的能力对比）。

## 步骤

### 1. 确定分镜粒度
根据任务需求选择分镜类型：
*   **微观 (Micro)**: 聚焦于单个案例的每一个交互细节。
*   **中观 (Meso)**: 聚焦于多个素材的布局、拼贴或对齐。
*   **宏观 (Macro)**: 聚焦于整个发布序列的叙事节奏。

### 2. 撰写分镜文档
文档应参考 `concepts/` 目录下的模式。

#### 单一案例 (Single Case) 模板内容:
1.  **Scene 1: Hook** - 使用素材 [X]，展示任务。
2.  **Scene 2: Input** - 使用素材 [Y]，执行 Zoom In 操作，定格 1.5s。
3.  **Scene 3: Execution** - 使用素材 [Z]，应用 4x 加速，展示“思考感”。
4.  **Scene 4: Output** - 使用素材 [W]，正常语速，全屏展示结果。

#### 演示集 (Showcase Set) 模板内容:
1.  **Section 1: Announcement** - 文字/Logo 素材。
2.  **Section 2: Capability Group** - 引用上述微观/中观分镜。
3.  **Section 3: Metrics** - 图表素材 [A, B]，展示 Benchmark。
4.  **Section 4: CTA** - 二维码/URL 截图。

### 3. 节奏与标注校对
*   检查每个分镜的时长，确保总时长符合“90秒原则”。
*   在文档中明确标注需要添加的“Luxury Tech”元素（如发丝边框、氛围光晕）。

## 输出
*   一份或多份 Markdown 格式的分镜策划书。
*   明确的合成逻辑说明。
