# 核心概念：左右分屏演示 (Split Screen Demo)

## 背景与目的
在涉及交互过程复杂的场景（如移动设备操控、Computer Use、Browser Use 或具身智能演示）时，单一视角的录屏往往无法同时兼顾“操作细节”与“全局反馈”。用户提出了“左右分屏演示”概念，旨在通过多维度视角的同步呈现，直观展示模型如何感知并改变其所处的环境。

---

## 概念定义
左右分屏演示是指将屏幕划分为两个（或更多）主要区域，同步展示不同的信息流。通常一侧展示“动作/指令端”（输入），另一侧展示“结果/环境端”（响应）。

## 典型应用场景与布局

### 1. 具身智能/机器人 (Embodied AI)
*   **左侧:** 用户的语音指令或模型内部的“思考链”（Chain of Thought）文本。
*   **右侧:** 机器人在真实物理环境或模拟环境中的动作执行视频。
*   **关联点:** 动作与指令的实时同步感。

### 2. Computer Use / Browser Use
*   **左侧:** 模型正在执行的底层指令流（如 JSON 指令、鼠标点击坐标或脚本输出）。
*   **右侧:** 真实的浏览器或操作系统界面录屏，展示鼠标移动、窗口切换。
*   **视觉处理:** 当模型点击某个特定按钮时，左侧指令高亮，右侧按钮出现光标波纹。

### 3. 移动设备操作 (Mobile Operation)
*   **左侧:** 用户在真机上的手势模拟（或指令输入）。
*   **右侧:** 手机屏幕的镜像输出。
*   **目的:** 证明模型能够精准理解移动端 UI 并执行复杂任务。

## 视觉与处理策略

### 1. 同步性 (Synchronization)
*   **核心要求:** 两侧的画面必须实现毫秒级的同步对齐。
*   **处理:** 处理器需根据时间戳精确对齐素材，确保“指令发出”与“反馈开始”之间没有视觉断层。

### 2. 视觉重心平衡 (Visual Balance)
*   **比例分配:** 默认为 50/50，但可根据信息重要性调整为 40/60 或 30/70。
*   **边框处理:** 使用“Luxury Tech”风格的极细边框（Hairline Border）分隔，增加高级感。

### 3. 连接线/标注 (Connectors)
*   **动态标注:** 在左右两屏之间使用动态线条或相同的光影效果，建立逻辑连接。例如，左侧指令中的某个单词与右侧被操作的图标同时闪烁。

## 核心设计原则
*   **信息不冗余:** 左右两屏展示的内容应互为补充，而非重复。
*   **低认知负荷:** 避免两侧同时出现过于复杂的文字，以免观众眼睛不知该看哪一侧。
