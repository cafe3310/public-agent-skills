# 核心概念：录制原始素材与处理 (Raw Assets & Processing)

## 背景与目的
高质量的演示视频始于对原始素材的精细处理。用户录制的原始素材通常包含多余的视觉范围和时间冗余，需要经过一系列标准化处理才能转化为可用于正式分镜的“初稿视频素材”。

---

## 原始素材类型 (Asset Types)

### 1. 代码 (Code/Text)
*   **来源:** IDE 截图、代码块复制。
*   **特性:** 文本形式，需关注语法高亮、缩进和可读性。

### 2. 提示词 (Prompts/Text)
*   **来源:** 对话框录屏、Markdown 文本。
*   **特性:** 演示的核心指令，通常需要突出显示。

### 3. 网页 (Webpages/Screenshots)
*   **来源:** 静态长截图、局部截图。
*   **特性:** 用于展示 UI 布局或生成结果。

### 4. 录像 (Screen Recordings)
*   **来源:** 浏览器录屏、真机操作录屏、系统 UI 录屏。
*   **特性:** 包含动态交互过程，是处理量最大的素材。

---

## 标准处理操作 (Processing Operations)

### 1. 裁剪 (Cropping - 空间维度)
*   **操作:** 去除屏幕四周的多余范围（如系统菜单栏、书签栏、底部 Dock）。
*   **目的:** 消除视觉干扰，聚焦于核心操作区域。

### 2. 修剪 (Trimming - 时间维度)
*   **操作:** 剪掉视频开头准备录制和结尾停止录制时的多余动作。
*   **目的:** 确保视频“入场”即开始，“出场”即结束。

### 3. 变速 (Time Warping)
*   **操作:** 识别模型推理、文本流式输出或文件下载等缓慢过程，进行加速处理（2x, 4x, 8x）。
*   **原则:** 保持视觉反馈的同时缩短观众等待时间。

### 4. 定格与缩放 (Freeze & Zoom)
*   **定格 (Freeze):** 在关键输入或重要结果出现的瞬间暂停 1-2 秒。
*   **缩放 (Zoom In):** 模拟摄像机推近效果，放大局部细节（如提示词的具体参数或生成的代码行）。

---

## 素材转化流程

1.  **收集:** 获取原始 `Raw Assets`。
2.  **清洗:** 应用上述裁剪、修剪等操作。
3.  **标准化:** 统一分辨率（如 1080p 或 4K）、帧率及纵横比。
4.  **产出:** 形成 **初稿视频素材 (First Draft Video Assets)**。

## 核心设计原则
*   **非破坏性:** 尽可能保留原始素材的高分辨率，以便在 Zoom In 时不失真。
*   **节奏感:** 变速操作应平滑，避免突兀的跳帧感。
*   **纯净度:** 最终初稿素材中不应包含任何与演示无关的系统 UI 元素。
