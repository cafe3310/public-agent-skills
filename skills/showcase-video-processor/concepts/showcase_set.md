# 核心概念：演示集 (Showcase Set)

## 背景与目的
“演示集”是模型发布材料中的最高层级，通常作为发布会的主视频、官网头条素材或技术报告的视觉核心。它不仅展示“模型能做什么”，更系统地回答了“它是谁”、“它有多强”以及“如何获取它”。

---

## 概念定义
演示集是一个高度集成、逻辑严密的叙事单元，将核心宣告、多维度能力演示、严谨的技术指标及商业信息整合在一起。

## 演示集的标准结构 (The Master Structure)

### 1. 核心宣告 (The Big Reveal / Important Info)
*   **目的:** 明确发布的对象（例如：全新一代旗舰模型 [模型名]）。
*   **视觉处理:** 使用高冲击力的视觉效果、Logo 动效及核心标语。
*   **核心讯息:** 模型的核心定位（如：全球最强的长文本理解模型）。

### 2. 能力介绍 (Capability Showcase - 核心演示群)
这是演示集的主体部分，通常由一系列不同模式的演示组成：
*   **组合运用:** 灵活运用 `Single Case Demo`（深度）、`Collage Showcase`（广度）、`Split Screen Demo`（交互逻辑）及 `Comparison Showcase`（优越性）。
*   **叙事线索:** 建议按“从易到难”或“从基础到惊艳”的逻辑编排演示序列。

### 3. 指标介绍 (Metrics & Technical Deep-Dive)
*   **内容:** 学术 Benchmark 评分、延迟 (Latency) 表现、Token 成本对比等。
*   **视觉处理:** 
    *   **动态图表:** 柱状图、折线图的动态增长效果。
    *   **Luxury Tech 审美:** 使用精致的排版、发丝边框和高对比度的深色看板。
    *   **学术严谨性:** 标注测试条件、Seed 值及引用来源。

### 4. 商业与获取信息 (Commercial & Sales Info)
*   **内容:** API 价格、订阅费用、开放时间、试用入口（二维码/URL）。
*   **视觉处理:** 简洁明了的定价卡片、清晰的 CTA（Call to Action）。

## 叙事与节奏策略

### 1. 结构化转场 (Structural Transitions)
*   演示集包含大量分镜，必须使用统一且高级的转场风格。
*   **建议:** 使用“淡入淡出到黑色”或“极简的位移转场”，避免花哨的特效干扰信息传递。

### 2. 情绪曲线 (Emotional Arc)
*   **开场:** 震撼（Hook）。
*   **中段:** 扎实（能力演示与指标）。
*   **收尾:** 激发行动（费用与入口）。

### 3. 视觉一致性 (Visual Consistency)
*   全片应维持统一的字体（推荐 Inter 或 Geist）、统一的配色方案（Luxury Tech 深色调）及统一的标注风格。

## 核心设计原则
*   **层级分明:** 观众应能清晰分辨出当前是在看“演示”还是在看“数据”。
*   **信息密度控制:** 能力介绍阶段允许高密度视觉（Collage），但在指标和费用阶段应回归极简，确保信息传达准确无误。
